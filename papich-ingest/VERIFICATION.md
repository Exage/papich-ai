# Проверка MVP

Проверено 25 сентября 2026 в доступном окружении macOS 27 arm64, Python 3.11. Полный набор версий — `requirements-tested.txt`. Это не benchmark Mac mini M1 8 GB: точная скорость и RAM на целевой машине не измерялись.

- `python -m pytest -q`: **27 passed**. Unit tests и pipeline-тесты с подменой тяжёлых стадий; Qdrant local и SQLite настоящие.
- `python -m pip check`: несовместимых зависимостей нет.
- Import MLX Whisper, sentence-transformers, Qdrant: успешно при доступе к Metal вне песочницы.
- Настоящий YouTube → аудио → ffmpeg → Whisper tiny → E5-small → Qdrant: успешно на публичном 19-секундном видео `jNQXAC9IVRw` («Me at the zoo»). Язык теста — английский. Поиск русским запросом «слоны в зоопарке» вернул видео с таймкодом и score **0.7608**. Повторный запуск с youtu.be-ссылкой вывел `Skipped`, без повторного скачивания или ASR.
- Настоящий русский Whisper **small** → E5-small → Qdrant → search: успешно на двух коротких синтетических записях macOS Milena про финансы и кулинарию. Запрос **«деньги»** поставил финансовую запись первой, score **0.8466**. Это проверка связности pipeline и тематического поиска, не оценка ASR на шумных стримах. В тексте были отдельные ошибки распознавания; они не скрывались и не переписывались. Повторяемая команда: `python -m tests.manual_smoke`.
- Проверено восстановление ASR-блоков после искусственного сбоя и порчи checkpoint, восстановление после сбоя embeddings и повреждения chunk JSON, пропуск повторов, force, пропущенная индексация, удалённые векторы, недоступное видео и продолжение очереди.

Не проверены в реальном прогоне: gated pyannote community-1 с пользовательским HF token, многочасовые стримы на M1 8 GB, age-restricted видео с cookies. Speaker alignment протестирован отдельно без скачивания модели. Полноценный запуск playlist зависит от текущей доступности записей YouTube; URL parsing и раскрытие playlist реализованы через yt-dlp.

Тестовые данные находятся отдельно от рабочей базы: `/tmp/papich-rag-smoke` и временный каталог `papich-russian-smoke-*`, веса тестов — `/tmp/papich-hf-cache`. Рабочая `data/` не содержит синтетических видео.
